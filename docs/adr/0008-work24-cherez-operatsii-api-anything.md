## Контекст
Пользователь попросил подключить Work24 через готовые операции API Anything (`goodnight000/api-anything`): `listItOrders`, `listOrders` и `getOrder` из `work24.json`, снятые с публичного интерфейса сайта без входа и ключа. Ленты заказов берутся из JSON `api.work24.ru/orders`. Это API, через который работает сам сайт, и в его `robots.txt` стоит `Disallow: /`. Карточки заказов `work24.ru/order/*` и страницы лент `robots.txt` не закрывает. Оферта Work24 автоматический сбор прямо не запрещает: поиск по словам «автоматическ», «парс», «робот», «скрипт», «сбор данных» дал только пункт об использовании материалов (2026-10-24). Пункт 1.3 запрещает контакты и ссылки в общении, штраф 500 ₽.

## Решение
Источник Work24 исполняет `work24.json` сам, на Python: GET по шаблону адреса, `extract` и `pick` для JSON, CSS-селекторы для HTML. Node.js и `api-anything` в образ не входят. Файл операций лежит в пакете (`freelance_bot/sources/work24.json`) без правок. Бот выполняет только операции `readOnly` уровня tier 1, без `volatile`; всё остальное он отклоняет как `ConfigError`. Браузерные заголовки из записи (`user-agent`, `sec-*`) не отправляются, бот представляется своим User-Agent. Полное описание запрашивается только для нового открытого заказа моложе `general.max_age_hours`: известные базе ID и закрытые карточки не открываются. Ограничения — до двух страниц ленты и 15 карточек за цикл, интервал 10 минут. Источник включён по просьбе пользователя. Отклики на Work24 не отправляются (ADR 0001).

## Почему
- Node.js и `api-anything` в Docker-образе: пакет собран из локального tgz и тянет playwright. Это лишний рантайм на общем сервере, и при tier 1 он не нужен. Не подошло.
- Разбирать страницу ленты `work24.ru/orders/razrabotka-i-it` (её `robots.txt` разрешает): данные лежат в сериализованном состоянии Nuxt, разбор хрупкий, и это не те операции, которые попросил пользователь. Оставлено запасным вариантом, если владелец решит не ходить в `api.work24.ru`.
- Открывать карточку каждого заказа из ленты: это десятки страниц по ~0,5 МБ за цикл ради уже виденных заказов. Не подошло.

## Последствия
- Правило «без скрытых API» (`docs/architecture.md`) имеет одно исключение — ленты Work24. Риск на владельце, как с Kwork (ADR 0003).
- Если Work24 сменит формат, ответы перестанут разбираться (`SourceFormatError`) и после трёх сбоев подряд придёт предупреждение. Тогда операции нужно переобучить через `api-anything` и заменить `work24.json`.
- Если в `<title>` карточки окажется текст заказа вроде «обойти captcha», это не блокировка: класс поля описания в ответе (`Fetcher.get_text(expect=)`) показывает, что пришли данные.
