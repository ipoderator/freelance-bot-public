# Ограничения и поломки источников

Сначала понять, что это за проблема, — от этого зависит, куда её писать.

| Что | Куда |
|---|---|
| Постоянное ограничение площадки: robots.txt, условия, API без ключа, формат ленты, что видно без входа | `docs/platforms.md`, раздел площадки: факт, дата проверки, чем подтверждено |
| То же, но это ловушка для кода («не делай X, иначе Y») | ещё одна строка в `AGENTS.md` → «Подводные камни» |
| Источник выключен из-за проблемы | комментарий в `settings.toml` над `enabled`: дата, причина, как включить обратно |
| Решение, как жить с ограничением (обходить, не собирать, собирать на риск владельца) | навык `adr` |

## Записать

1. **Не дублировать.** `grep -n "<площадка или слово>" docs/platforms.md AGENTS.md settings.toml`;
   есть — обновить запись, а не добавлять вторую.
2. **Доказательство — без запуска сбора.** `once` и `run` ходят в сеть (`AGENTS.md`), для
   диагноза хватает флагов в базе: `last_ok:<платформа>`, `last_error:<платформа>`,
   `fail_count:<платформа>`, `blocked_until:<платформа>`, `bootstrapped:<платформа>`:
   ```bash
   .venv/bin/python -c "import sqlite3; c = sqlite3.connect('data/bot.sqlite3'); print(c.execute(\"select key, value, updated_at from flags where key like '%:work24'\").fetchall())"
   ```
   То же видно в `/status` бота. Прогон `once --dry-run --console` с отдельной `--db` —
   только по просьбе пользователя.
3. **Формат записи** — одна строка: площадка, что происходит, с какого числа, чем
   подтверждено (флаг, текст ошибки, ответ сервера), обход, что закроет проблему и кто
   это делает (код / пользователь / площадка). Пример:
   `- Work-zilla: лента демонстрационная (isStaticOrders: true, 2026-10-24) — источник выключен; закроет доступ к ленте у аккаунта, затем workzilla-session и enabled = true`.
4. **Там, где живёт обход**, — ссылка на запись: комментарий в коде или `settings.toml`,
   причина `pytest.skip`, текст ошибки источника.

## Закрыть

1. Убедиться, что починено: флаг `last_ok:<платформа>` свежее `last_error:`, тест на
   фикстуре проходит.
2. `docs/platforms.md` — переписать на текущую правду (это справочник, а не журнал).
4. Комментарий в `settings.toml` и ловушку в `AGENTS.md` — убрать или исправить, если они
   больше не верны.
