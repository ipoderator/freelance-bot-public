## Контекст
2026-10-24 пользователь попросил «подключи API SuperJob» — как источник вакансий для себя и для пользователей публичного бота (ADR 0011). Для посторонних HH через Хэдди не подходит (сессия Telegram = полный доступ к аккаунту), а бот-секретарь Telegram Business без Premium недоступен (проверено 2026-10-24). Сайт hh.ru парсить нельзя (условия, ADR 0009).

Проверено 2026-10-24 (`docs/platforms.md`, §7):
- `GET https://api.superjob.ru/2.0/vacancies/` без ключа — 403 «Необходимо передать ключ приложения. Зарегистрироваться можно по адресу https://api.superjob.ru/register/». Регистрация приложения требует входа в аккаунт SuperJob. Ключ (Secret key) — заголовок `X-Api-App-Id`.
- Справочник разделов `GET /2.0/catalogues/` отвечает без ключа: «IT, Интернет, связь, телеком» — 33, в нём «Разработка, программирование» — 48, «Нейросети / Искусственный интеллект» — 650, «AI» — 651.
- Документация API: поиск по `keyword`, `catalogues`, `place_of_work` (2 — «на дому»), `date_published_from` (unixtime), `order_field=date`, `count` до 100, не больше 500 результатов на поиск; лимит — 120 запросов в минуту с IP. Без авторизации пользователя — только вакансии в открытом доступе, без контактов. Отдельных правил использования на странице API не нашлось.
- `api.superjob.ru/robots.txt` — `Disallow: /` для роботов-индексаторов; API с ключом приложения — официальный путь для программ.

## Решение
Источник `superjob` (`freelance_bot/sources/superjob.py`): за цикл по запросу на каждое слово из `queries`, свежие сверху, не старше `max_age_hours`, до 100 за запрос; по желанию `catalogues` и `remote_only`. Вакансия — как у HH (`VACANCY_PLATFORMS`): режим `notify`, карточка с компанией, городом («удалённо» для «на дому»), зарплатой и датой публикации, без черновика и цены; суть — без нейросети. Требуемый опыт идёт в описание как «Опыт работы от N лет», чтобы его увидел скоринг. Бюджет — только для рублёвых зарплат. Ключ — `SUPERJOB_API_KEY` в `.env`, вырезается из логов. 403 — ошибка ключа с подсказкой, а не «похоже на CAPTCHA».

SuperJob добавлен в площадки анкеты публичного бота. В `settings.toml` источник выключен, пока нет ключа.

## Почему
- Официальный API: разрешённый путь, стабильный JSON, без парсинга страниц.
- Слова поиска, а не только разделы: в разделе «Разработка, программирование» много не-Python вакансий, отбор всё равно делает скоринг.

## Последствия
- Живой ответ API не проверен: ключа нет. Фикстура `tests/fixtures/superjob_vacancies.json` собрана по примеру ответа из документации; при первом прогоне с ключом сверить поля (`link`, `date_published`, `place_of_work`, HTML в `work`).
- Пользователю нужно: войти на superjob.ru, зарегистрировать приложение на api.superjob.ru/register/, вписать Secret key в `.env` (`SUPERJOB_API_KEY`), прогнать `once --platform superjob --include-disabled`, затем `enabled = true` и деплой `--with-env`.
