## Контекст
2026-10-25 пользователь попросил брать вакансии из публичных Telegram-каналов полностью автоматически — без пересылки постов и без сессии пользователя. На вопрос о способе выбрал «Веб-превью t.me/s» (без аккаунта), о каналах: «найди вакансии по всей России которые выкладывают, что бы потом уже персонально под каждого человека подбирать вакансии». Из найденного выбрал «Только сеть 18 каналов» (2026-10-25).

Проверено 2026-10-25 (`docs/platforms.md`, §9):
- `https://t.me/robots.txt` — 404 (запретов для программ нет).
- `https://t.me/s/<канал>` — 200, ~130 КБ, без входа: 20 последних постов (`data-post="канал/ID"`), текст в `.tgme_widget_message_text`, время — `<time datetime="…+00:00">`; более ранние — `?before=<ID>`.
- Условия Telegram (`telegram.org/tos/content-licensing`, на них ссылается `core.telegram.org/api/terms`, п. 1.5): доступ к пользовательскому контенту иначе как «ordinary, legitimate, and intended use … as its user» запрещён; отдельно запрещены «scraping, indexing, harvesting, aggregation or use of data … to … deployment of artificial intelligence». Пользователь предупреждён, риск (включая блокировку IP общего сервера, где работают и другие сайты) — на нём, как с Kwork (ADR 0003) и Work24 (ADR 0008).
- Bot API не подходит: бот получает посты канала, только если он там админ. Telegram Business видит лишь личные чаты и требует Premium. Сессию Telegram посторонних бот не берёт (ADR 0011).
- Каналы из подборок (Нетология, vc.ru, mel.fm, tlgrm.ru) и перебор имён `rabota_<город>`, `vakansii_<город>` по 66 городам: живая сеть городских каналов — 18 каналов в 12 городах (Москва, Санкт-Петербург, Казань, Краснодар, Ростов-на-Дону, Самара, Уфа, Пермь, Тюмень, Омск, Сочи, Смоленск), у каждого последний пост — час назад, ~8 вакансий в день. Формат один: `<b>Должность</b>`, строка зарплаты («96000 ₽», «5400 - 6000 ₽», «Зарплата по договоренности.»), блоки `<b>Обязанности:</b>`, `<b>Требования:</b>`, `<b>Мы предлагаем:</b>`, `<b>Контакты:</b>` с телефоном. Профессии любые: повар, сварщик, бухгалтер, медсестра.
- В сети ~15% постов — реклама (контрактная служба, букмекер): без блоков «Обязанности»/«Требования», со ссылками clck.su, trk.ppdu.ru. Каналы одного города частично повторяют друг друга (3–9 из 18 постов).
- Не взяты: сеть «Только отборные вакансии <города>» (Барнаул, Сургут, Тольятти…) — перепосты hh.ru, а с hh.ru бот ничего не берёт (ADR 0009); каналы в свободной форме (Новосибирск, Нижний Новгород) — по нескольку вакансий в посте, правилами не разобрать; отраслевые digital/IT-каналы — без города; `vacansi_msk` — одни и те же рекламные посты.

## Решение
Площадка `tgchannels` (`freelance_bot/sources/tgchannels.py`, `VACANCY_PLATFORMS`): карточка вакансии без черновика, как SuperJob.

- Каналы — `[sources.tgchannels] channels` в `settings.toml`: имя канала → город. Город вакансии — город канала.
- Читается только первая страница `t.me/s/<канал>` (20 постов), без `?before=`. Как «Работа России» (ADR 0015), только под анкету: `AnketaVacancies` при сборе владельца и `VacancySearch` в подборке после анкеты — каналы её города, все каналы — если в анкете выбраны другие города или города в резюме нет. Сбор — раз в 30 минут, ответ кэшируется на 10 минут.
- Вакансия — пост с блоком «Обязанности» или «Требования»; остальное (реклама, объявления канала) пропускается. Название — первая строка, зарплата — вторая.
- Блок «Контакты» и всё после него отрезается, телефоны, почта, `@ник` и ссылки из текста вырезаются (там телефоны частных лиц). В карточке — ссылка на пост `https://t.me/<канал>/<ID>`.
- Нейросеть тексты постов не видит: суть 📝 — начало описания (`summary.BUILTIN_ONLY` = `VACANCY_PLATFORMS`), черновиков у вакансий нет.
- ID вакансии — хэш названия и описания: один пост в нескольких каналах и его повтор через неделю — одна вакансия.

## Почему
- Сессия Telegram пользователя (как HH, ADR 0009) — полный доступ к аккаунту, а посторонним её не дать (ADR 0011); пересылка постов — не «полностью автоматически».
- Bot API — бот не может читать чужие каналы.
- Отбор нейросетью из свободного текста — прямо запрещён условиями Telegram; правила справляются, потому что формат сети один.
- Все найденные каналы сразу — перепосты hh.ru нарушили бы ADR 0009, а свободный формат дал бы мусор; пользователь выбрал только сеть.
- Листать `?before=` — в 2–3 раза больше запросов ради вакансий старше 2–3 дней, а сбор каждые 30 минут и так видит каждый пост.

## Последствия
- Сбор нарушает условия Telegram — решение пользователя; t.me может ограничить IP сервера. Признак — 429/403 или страница без постов: площадка встаёт на паузу, как при блокировке. Тогда — `known-issue`, а не обход.
- Если канал закроют или сменят формат — посты без «Обязанности»/«Требования» просто пропадут; пусто из всех каналов при живых страницах — повод проверить разметку (`SourceFormatError`, если на странице нет постов вообще).
- Городов без канала в сети (Екатеринбург, Новосибирск, Нижний Новгород…) площадка не покрывает; новый канал — строка в `channels`, если у него тот же формат.
- Повторы одной вакансии с разным текстом (разные каналы города переписывают пост) хэш не ловит — их схлопывает `matching.drop_repeats` по названию и городу.
- Публичным пользователям рассылки по анкете ещё нет (этап 2, ADR 0011): каналы у них — в подборке после анкеты и по кнопке «Заказы по анкете».
