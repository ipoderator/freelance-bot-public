## Контекст
Бриф требует персональный отклик под конкретное ТЗ, но не говорит, чем его генерировать. Вопрос об этом остался без ответа, принята рекомендация. У владельца нет обязательного ключа к внешней LLM.

## Решение
По умолчанию черновик строит встроенный генератор без внешних сервисов, от текста ТЗ, с вариативными формулировками и проверкой похожести на последние черновики. Если владелец сам впишет ключ Anthropic в `.env`, используется LLM с теми же валидатором и откатом на встроенный при ошибке или нарушении.

## Почему
- Только LLM: бот не работал бы без ключа и платной подписки, а текст зависел бы от внешнего сервиса. Не подошло.
- Один фиксированный шаблон: бриф прямо запрещает одинаковые шаблоны. Не подошло.
- Отправлять ТЗ в сторонний сервис по умолчанию: данные заказчиков уходят наружу без согласия владельца. Не подошло, это делается только по его ключу.

## Последствия
- Встроенный текст беднее по стилю, чем у модели; качество откликов растёт только после подключения ключа.
- Две реализации одного интерфейса надо держать согласованными; общий валидатор обязателен.
- При включённом LLM описания проектов уходят внешнему провайдеру, и это решение владельца.
- Допущение принято без подтверждения пользователя и может быть пересмотрено.
