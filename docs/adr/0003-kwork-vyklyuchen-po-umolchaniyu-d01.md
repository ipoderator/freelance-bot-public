## Контекст
План исходил из того, что публичную страницу Kwork можно читать: robots.txt разрешает `/projects`. Исследование площадок показало, что пользовательское соглашение Kwork запрещает автоматический процесс для отслеживания и сбора данных.

## Решение
Источник Kwork по умолчанию выключен. Включает его сам владелец флагом в настройках, понимая риск; README и `/status` показывают предупреждение об условиях Kwork. Решение остаётся за пользователем, бот сам его не принимает.

## Почему
- Включить по умолчанию, раз robots.txt разрешает: техническое разрешение не отменяет соглашения. Не подошло, потому что нарушение условий может стоить владельцу аккаунта продавца с накопленной репутацией.
- Убрать Kwork совсем: отвергнуто, так как бриф называет Kwork площадкой первого этапа, а риск принимает владелец аккаунта, не мы.
- Молча собирать без предупреждения: не подошло, пользователь должен знать о риске в момент включения.

## Последствия
- Из коробки бот работает только с FL.ru; Kwork надо включить осознанно.
- Отключённый Kwork не должен засорять статистику и статусы, но его нужно уметь прогонять для проверки отдельно.
- Если владелец включит сбор, ответственность за условия площадки на нём; тихо снять предупреждение нельзя.
