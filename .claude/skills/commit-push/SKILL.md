# Коммит и пуш

Вызов навыка и есть просьба закоммитить и запушить — переспрашивать не нужно.
Останавливаться и спрашивать только при условиях из «Стоп».

## Шаги

1. **Состояние:** `git status --short`, `git diff --stat`, `git log --oneline -5`,
   `git status -sb` (ветка, впереди/позади `origin`).
2. **Что коммитить.** Только файлы этой правки (код, тесты, документация, записи о
   правке). Постороннее — не добавлять и назвать в отчёте. Не `git add -A` вслепую.
   Никогда: `.env`, `.env.bak`, `data/*.sqlite3`, `.claude/settings.local.json`,
   `profile/resume.pdf`.
3. **Секреты в индексе** — только имена файлов, не значения:
   ```bash
   git diff --cached --name-only
   git diff --cached | grep -cE '[0-9]{8,10}:[A-Za-z0-9_-]{35}|sk-ant-|gsk_[A-Za-z0-9]{20}|Bearer[= ][A-Za-z0-9._-]{20,}'   # 0
   ```
   Не 0 — разобрать каждое совпадение; настоящий секрет — стоп.
4. **Проверки:** `make check` зелёный в этом состоянии дерева. Падает — не коммитить.
5. **Сообщение** по правилам проекта: заголовок — что (`fix: даты в одном формате`,
   `feat: …`, `docs: …`), тело — почему; трейлер `Requirements: RNN`, если правка касается
   требования автопилота; в конце — строка соавторства из system-reminder сессии.
   ```bash
   git commit -q -m "fix: …" -m "Почему: …" -m "Co-Authored-By: …"
   ```
   Хук упал — исправить причину и сделать новый коммит; без `--no-verify`, без `--amend`
   уже запушенного. Заголовок `Autopilot: сборка сдана` — только у автопилота.
6. **Пуш** в рабочую ветку `master` напрямую (веток и PR в процессе нет):
   `git push origin master`. Отклонён как non-fast-forward — `git pull --rebase origin master`,
   снова `make check`, снова пуш. Без `--force`.
7. **Проверки на GitHub** — по полному SHA:
   `gh run list --commit "$(git rev-parse HEAD)"`. Сейчас workflow в репозитории нет
   (`.github/` отсутствует) — так и сказать, а не «CI зелёный».

## Стоп (спросить пользователя)

- в коммит попадёт секрет или `.env`;
- проверка падает, а починка вне этой правки;
- пуш отклонён не из-за non-fast-forward (доступ, защищённая ветка);
- непонятно, какие из нескольких несвязанных изменений входят в коммит.

## Отчёт

Хеш и заголовок коммита, ветка, результат пуша, что показал `gh run list`, какие файлы
намеренно не вошли.
