# Freelance Bot

Telegram-бот для фрилансера-разработчика. Следит за новыми заказами на FL.ru, Work24, Freelance.ru
(и, по желанию, Kwork и Work-zilla), отбирает подходящие под профиль, присылает карточку и готовый
персональный черновик отклика.
Бот **ничего не отправляет на биржи сам**: официального способа автоотклика нет ни у FL.ru,
ни у Kwork, на Work24, Freelance.ru и Work-zilla отправка не делается (подробности —
`docs/platforms.md`). Отклик вы отправляете вручную.

## Что работает, а что нет

| Работает | Не работает / не делается |
|----------|---------------------------|
| Сбор проектов FL.ru из официального RSS (4 ленты) | Автоотправка откликов: нет подтверждённого способа, режим `auto` всегда превращается в `draft` |
| Сбор Kwork с публичной страницы биржи (включён пользователем на свой риск, см. ниже); Work24 и Freelance.ru — готовыми операциями API Anything, с полным ТЗ из карточки; Work-zilla — операциями с вашей сессией, только когда лента настоящая | Вход на биржи, обход CAPTCHA, прокси, покупка откликов, коннектов и PRO |
| Отбор и ранжирование по направлениям из `settings.toml` | Число откликов на FL.ru: RSS его не отдаёт, в карточке «нет данных» |
| Черновик отклика (встроенный генератор или нейросеть по ключу: Groq, GPT или Claude) с ориентировочной ценой и сроком (🧮 в карточке) | Оценка цены — эвристика по типу заказа и бюджету, а не расчёт по ТЗ: проверьте перед отправкой |
| Команды `/status /pause /resume /filters /stats /last`, кнопки под карточкой; цена и срок вписываются в отклик по вашему сообщению | Бот отвечает только владельцу (`TELEGRAM_OWNER_ID`) |
| Работа на сервере в Docker (`compose.yaml`), запасной вариант — launchd на Mac; дедупликация, паузы, защита от блокировок | Запуск через launchd вживую не проверялся |

## Своя копия бота: настройка за 5 минут

Бот личный: у каждого свой бот в Telegram, свои ключи и свои данные. Чужой бот ваших
заказов не видит, а ваш отвечает только вам и только в личном чате.

1. Установите Python 3.11+ и скачайте проект, затем в его папке:
   `python3 -m venv .venv && .venv/bin/pip install -e .`
2. В Telegram создайте бота: @BotFather → `/newbot` → имя и username (оканчивается на `bot`).
3. Запустите мастер: `.venv/bin/python -m freelance_bot init`. Он спросит:
   - токен бота (ввод не отображается) и проверит его в Telegram;
   - ваш Telegram ID — узнает сам, когда вы напишете своему боту `/start`;
   - ключ OpenAI или Anthropic — необязательно, без него отклики пишет встроенный шаблон;
   - имя для подписи, стаж разработки, делали ли вы ботов и AI-агентов, факты опыта;
   - направления заказов и свои ключевые слова, порог отбора, расписание списков, Kwork.
4. Запуск: `.venv/bin/python -m freelance_bot run` (или на сервере: `docker compose up -d --build`).

Что мастер записывает: `.env` (секреты, права 600, в Git не попадает), `profile/profile.toml`
(профиль) и `settings.toml` (отбор). Прежние файлы сохраняются рядом как `*.bak`. Данные
никуда не отправляются: мастер обращается только к Telegram. Отклик бот пишет **только из
ваших фактов** — опыт он не выдумывает, а стаж больше указанного в отклик не пропустит.

## Установка на Mac

Нужен Python 3.11 или новее.

```bash
cd freelance-bot
python3 -m venv .venv
.venv/bin/pip install -e '.[dev]'
cp .env.example .env
```

Проверка: `make check` (линтер и тесты, сеть не нужна).

## Бот в Telegram: пять шагов в @BotFather

1. Откройте в Telegram `@BotFather` и отправьте `/newbot`.
2. Введите имя бота (любое, например «Мои заказы»).
3. Введите username: латиница, оканчивается на `bot`, например `gleb_orders_bot`.
4. BotFather пришлёт токен вида `123456:ABC...`. **Никому не показывайте его и не публикуйте** (в чате, в Git, в скриншотах).
5. Откройте файл `.env` в папке проекта и впишите токен: `TELEGRAM_BOT_TOKEN=...`.

Дальше проверьте токен и узнайте свой user_id:

```bash
.venv/bin/python -m freelance_bot setup-telegram
```

Команда проверит токен (getMe), зарегистрирует меню команд (/start, /status, /pause, /resume,
/filters, /stats) и до 120 секунд будет ждать, пока вы напишете боту `/start`. Затем она
напечатает ваш user_id: впишите его в `.env` как `TELEGRAM_OWNER_ID=...`. Токен команда не печатает.

## Файл `.env`

Секреты лежат только здесь, файл в `.gitignore`.

| Переменная | Зачем |
|------------|-------|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
| `TELEGRAM_OWNER_ID` | ваш числовой user_id: только вам бот отвечает и присылает карточки |
| `ANTHROPIC_API_KEY` | необязательно: черновики через Claude; пусто — встроенный генератор |
| `LLM_MODEL` | модель Claude для черновиков (по умолчанию из `.env.example`) |
| `OPENAI_API_KEY` | необязательно: черновики и суть заказа через GPT; задан — важнее ключа Anthropic |
| `OPENAI_MODEL` | модель GPT (по умолчанию `gpt-5-mini`; `gpt-5` — тексты лучше, дороже) |
| `GROQ_API_KEY` | необязательно: черновики и суть через Groq (бесплатный тариф, ключ на console.groq.com/keys); задан — важнее ключей OpenAI и Anthropic |
| `GROQ_MODEL` | модель Groq (по умолчанию `openai/gpt-oss-120b`; `openai/gpt-oss-20b` — быстрее; `llama-3.3-70b-versatile`) |

## Настройки (`settings.toml`)

Файл с комментариями; после правки перезапустите бота.

- **Режимы** `sources.fl.mode` / `sources.kwork.mode`: `notify` (только карточка), `draft` (карточка и черновик), `auto` (отправка). `auto` сработает только при всех условиях безопасности (подтверждённый официальный способ отправки, бесплатный отклик, заданные цена и срок, дневной лимит больше 0, для Kwork лимит коннектов, не dry-run). Сейчас способа отправки нет, поэтому `auto` превращается в `draft`, а причина видна в карточке строкой «auto → draft: …».
- **Лимиты**: `daily_auto_limit` (отправок в сутки, 0 — ни одной), `kwork.connects_daily_limit` (коннектов Kwork в сутки, 0 — ни одного).
- **Цена и срок**: `[offer] price_rub` и `days` — одна цена на все отклики. Пусто (`""`, сейчас так) — бот ставит ориентировочную цену и срок под каждый заказ (`freelance_bot/pricing.py`): вилка по типу работы (парсер, бот, интеграция, AI-агент, сервис/MVP, доработка), поправка на сложность (оплата, админка, LLM, несколько сайтов…), затем бюджет заказчика: если он не ниже оценки, предлагается бюджет; ниже — на Kwork не выше допустимого бюджета и срока заказчика, на FL — нижняя граница вилки. Оценка и её основание — строка «🧮 Оценка» в карточке, в `/last` и в вопросе о цене. Своя цена — кнопкой «💬 Цена и срок», она заменяет оценку. Вилки — константы `TIERS` в `pricing.py`.
- **Свежесть и порог**: `max_age_hours` (6) и `min_score` (30; было 40, снижено 2026-10-22 ради большего числа заказов).
- **Направления, исключения, бонусы пересечений**: разделы `[directions.*]`, `[exclusions]`, `[[intersections]]`.
- **Контакты в откликах**: по умолчанию выключены. Чтобы добавить, впишите контакт в `[contacts]` файла `profile/profile.toml` и поставьте `include_in_responses = true`.
- **Ленты FL.ru**: `sources.fl.urls`, четыре ленты `/rss/all.xml?category=N` (Программирование, AI, Автоматизация, Мессенджеры).
- **Только бесплатные отклики FL.ru**: `sources.fl.only_free_responses` (сейчас `false`: с 2026-10-22 бот присылает и заказы с платным откликом). Без PRO отклик на FL.ru бесплатен только у заказов с меткой «для всех» (а также вакансий и конкурсов), и то после верификации аккаунта; на остальные заказы отклик покупается — от 80 ₽ за штуку (`docs/platforms.md`, §1). Поэтому такие проекты бот не присылает: они получают статус «отсечён» с причиной «платный отклик» и учитываются в `/stats` в строке «отсечено». Поставьте `false`, если готовы платить за отклики, — тогда они приходят с пометкой «💰 отклик платный». Карточка заказа «для всех» помечена «🆓 бесплатный отклик (нужна верификация FL)». На Kwork настройка не действует: там отклик тратит бесплатный коннект.
- **Генерация AI-контента** (`[exclusions] ai_content`): заказы, где AI — это работа в готовом сервисе видео, картинок или озвучки (Higgsfield, Midjourney, Runway, Kling, Suno…) без API, бота или backend, отсекаются как «вне профиля».
- **Слабое совпадение**: если совпали только общие слова (сервер, ии, api, скрипт, crm… — `WEAK_TERMS` в `scoring.py`) и либо одним упоминанием в описании, либо при бюджете меньше 2000 ₽, заказ отсекается («Настройка VPS» за 500 ₽ из-за слова «сервер» в описании). Бюджет меньше 2000 ₽ вообще снижает балл.
- **Не разработка** (`marketing`, `teaching`, `manual_qa` в `[exclusions]`): SMM и продвижение, наставничество и учебные работы, ручное тестирование — отсекаются, если перевешивают профиль.

## Work24: операции API Anything

Лента заказов «Разработка и IT» и полное описание из карточки заказа берутся готовыми
операциями [API Anything](https://github.com/goodnight000/api-anything) из
`freelance_bot/sources/work24.json`; бот выполняет их сам, Node.js не нужен. Карточка
открывается один раз и только для нового открытого заказа. API `api.work24.ru` закрыт в
его `robots.txt` — источник включён по решению пользователя (ADR 0008, `docs/platforms.md`, §3).
Настройки — `[sources.work24]` в `settings.toml`: `enabled`, `interval_sec`, `operations`
(`listItOrders` — «Разработка и IT», `listOrders` — все разделы). Разово:
`.venv/bin/python -m freelance_bot --db data/dry-run.sqlite3 once --dry-run --console --platform work24`.
Если Work24 сменит формат, бот после трёх сбоев подряд пришлёт предупреждение — тогда
переобучите операции через `api-anything` и замените `work24.json`.

## Freelance.ru и Work-zilla: операции API Anything

**Freelance.ru** (`[sources.freelance_ru]`, включён). Бот раз в 10 минут читает первую страницу
`freelance.ru/task` (адреса с `?page=` закрыты в robots.txt) и открывает карточку только нового
публичного задания из разделов `categories` (по умолчанию «Веб-разработка и IT» и «ИИ и
Нейросети»), не больше 10 за цикл. Задания «Только для Премиум» пропускаются: их текст без
премиум-доступа закрыт. Контакты заказчика из текста вырезаются. Входа и ключей не нужно.
Разовый прогон: `.venv/bin/python -m freelance_bot --db data/dry-run.sqlite3 once --dry-run --console --platform freelance_ru --max-age-hours 48`.

**Work-zilla** (`[sources.workzilla]`, выключен). Ленту видит только ваш аккаунт исполнителя.
Пока в кабинете не пройдены обязательные шаги, Work-zilla отдаёт демонстрационные задания
(`isStaticOrders: true`). Бот их не сохраняет и не присылает, а в `/status` пишет «лента
демонстрационная». Запуск:

1. Войдите в Work-zilla через `api-anything` (как в пробе), затем перенесите сессию в `.env`,
   значения на экран не выводятся:
   `.venv/bin/python -m freelance_bot workzilla-session --from <API_ANYTHING_HOME>/sessions/work-zilla.json`
   (пишет `WORKZILLA_COOKIE` и `WORKZILLA_AGENT_ID`, права 600).
2. Проверьте ленту: `.venv/bin/python -m freelance_bot --db data/dry-run.sqlite3 once --dry-run --console --platform workzilla --include-disabled`.
3. Когда вместо «лента демонстрационная» придут задания, поставьте `enabled = true` в
   `[sources.workzilla]`. Если бот работает на сервере, обновите там `.env` и перезапустите его.

Интервалы — `interval_sec` (по умолчанию 600 с, меньше 60 не бывает) и `jitter_sec` в
`settings.toml`, секреты — только в `.env`. Ошибки площадки видны в `/status`; после трёх
сбоев подряд бот пришлёт одно предупреждение, при блокировке (403, CAPTCHA) — пауза на час.
Если площадка сменит разметку, переобучите операции через `api-anything` и замените
`freelance_bot/sources/freelance-ru.json` или `work-zilla.json` (ADR 0010, `docs/platforms.md`, §5–6).

## SuperJob: вакансии через официальный API

`[sources.superjob]` выключен, пока нет ключа. Вакансии приходят карточкой (компания, город,
зарплата, дата публикации), как HH: откликаетесь на сайте сами, черновиков бот не пишет.

1. Войдите на superjob.ru и зарегистрируйте приложение: https://api.superjob.ru/register/.
2. Ключ (Secret key) со страницы https://api.superjob.ru/info/ впишите в `.env`:
   `SUPERJOB_API_KEY=…`.
3. Проверьте: `.venv/bin/python -m freelance_bot --db data/dry-run.sqlite3 once --dry-run --console --platform superjob --include-disabled --max-age-hours 48`.
4. Поставьте `enabled = true` в `[sources.superjob]`. На сервере — деплой с `--with-env`.

Что искать — `queries` (по запросу к API на слово за цикл), `catalogues` (ключи разделов из
https://api.superjob.ru/2.0/catalogues/, например 48 — «Разработка, программирование»),
`remote_only = true` — только удалённая работа (ADR 0012, `docs/platforms.md`, §7).

## Kwork: включён на ваш риск

Пользовательское соглашение Kwork запрещает автоматический сбор данных с сервиса
([текст соглашения](https://kwork.ru/terms_of_service); разбор — `docs/platforms.md`, §2.2).
Поэтому в коде Kwork считается рискованным источником; в этом `settings.toml` он включён
по решению пользователя (2026-10-22). Выключить: `enabled = false` в `[sources.kwork]`.
Как он включается:

1. В `settings.toml` в разделе `[sources.kwork]` поставьте `enabled = true`.
2. Перезапустите бота. С включённым Kwork бот печатает предупреждение при запуске, и оно же показывается в `/status`.
3. Разово, без правки настроек: `.venv/bin/python -m freelance_bot once --dry-run --console --platform kwork --include-disabled`.

Отклик на Kwork расходует ограниченный коннект (около 30 в месяц), автоотправка не делается.

## Dry-run: проверка без отправок

```bash
.venv/bin/python -m freelance_bot once --dry-run --console
```

Один реальный цикл сбора: запросы к биржам идут, карточки и черновики печатаются в консоль,
на биржи ничего не отправляется. Без токена консоль включается сама. Короткая форма —
`.venv/bin/python -m freelance_bot once --console` (без `--dry-run` действует `general.dry_run`
из `settings.toml`; автоотправки всё равно нет). Полезные ключи:

- `--platform fl|kwork` — одна площадка;
- `--max-age-hours 48` — окно свежести пошире, чтобы увидеть больше примеров;
- `--db data/dry-run.sqlite3` (ключ ставится до `once`) — отдельная база, чтобы проверка не пометила проекты просмотренными в рабочей базе.

Результат реального прогона — в `docs/dry-run-2026-10-21.md`. На первом запуске всё, что старше
`max_age_hours`, помечается просмотренным без уведомлений, чтобы бот не засыпал старыми заказами.

## Запуск

```bash
.venv/bin/python -m freelance_bot run            # бот + расписание сбора
.venv/bin/python -m freelance_bot run --dry-run  # то же, без отправок на биржи
```

Остановка: Ctrl+C. В Telegram:

| Команда | Что делает |
|---------|------------|
| `/status` | работает или на паузе, режимы площадок, последний успешный сбор, ошибки |
| `/pause`, `/resume` | остановить и возобновить сбор и уведомления (переживает перезапуск) |
| `/filters` | направления, исключения, порог, возраст, режимы и лимиты |
| `/stats` | за сегодня и за 7 дней: собрано, отсечено, прислано, черновиков, откликнулся, отправлено авто |
| `/last` | до 10 лучших подходящих заказов за 7 дней (и присланных, и скрытых при первом запуске или по возрасту), кроме тех, где вы нажали «Откликнулся» или «Пропустить»; заказы с платным откликом — только при `only_free_responses = false`; кнопка у каждого — указать цену и срок |

Под заголовком карточки — «📝» и суть заказа в одно-два предложения: что сделать, на чём,
важные условия. Её пишет нейросеть (Groq, GPT или Claude — у кого задан ключ и есть лимит),
иначе — первые предложения описания. Та же суть показывается в `/last` и при выборе заказа.

Под карточкой четыре кнопки: «✅ Откликнулся», «⏭ Пропустить», «💬 Цена и срок», «🔄 Другой вариант» (новый черновик).

**Как откликнуться.** Нажмите «💬 Цена и срок» под карточкой (или выберите заказ в `/last`) и
напишите цену в рублях и срок в днях, например `15000, 5` (понимает и `15 000 ₽ 5 дней`, `15к/5`).
Бот подставит их вместо `[ЦЕНА]` и `[СРОК]` в последний черновик этого заказа и пришлёт готовый
текст блоком, который копируется одним нажатием, с кнопками «🔗 Открыть заказ» и «✅ Откликнулся».
Если в тексте остались другие метки (например, `[ПРИМЕРЫ РАБОТ — впиши]`), бот напомнит их заполнить.
Сам отклик на бирже отправляете вы: официального способа отправки нет (`docs/platforms.md`).
Меню команд бот обновляет сам при каждом запуске.
Проект с меткой «для всех» на FL.ru помечен «🆓 бесплатный отклик (нужна верификация FL)»; при
`only_free_responses = false` остальные проекты FL.ru приходят с пометкой «💰 отклик платный».

## Запуск в Docker

```bash
docker compose up -d --build   # образ из Dockerfile, .env рядом с compose.yaml, база — ./data
docker compose logs -f         # логи
```

В `compose.yaml` нет портов наружу (Telegram опрашивается исходящими запросами), лимиты
256 МБ RAM и 0,5 CPU, логи ротируются, healthcheck проверяет успешный сбор за 30 минут.
`settings.toml` и `profile/profile.toml` зашиты в образ — после правки пересоберите его.


**Не запускайте бота одновременно в двух местах** (Mac, сервер): Telegram отдаёт обновления только
одному процессу, второй получит ошибку Conflict, а карточки будут приходить дважды.

## Работа в фоне на Mac (launchd, запасной вариант)

```bash
scripts/install_launchd.sh     # LaunchAgent: старт при входе в систему, перезапуск при падении
scripts/uninstall_launchd.sh   # снять
```

Скрипт пишет `~/Library/LaunchAgents/local.freelance-bot.plist` и загружает его через
`launchctl bootstrap`. Для установки нужны готовый `.venv` и заполненный `.env`. Логи — в
`logs/freelance-bot.log` (папка в `.gitignore`). Посмотреть план без установки: `scripts/install_launchd.sh --print`.
Состояние: `launchctl print gui/$(id -u)/local.freelance-bot`.

## Частые проблемы

- **«Токен бота не задан»**: заполните `.env` (см. шаги выше).
- **Бот молчит**: проверьте `/status` (не пауза ли), `TELEGRAM_OWNER_ID` и что `min_score` не слишком высок. После первого запуска старые проекты не присылаются.
- **Ошибка источника**: после 3 неудач подряд приходит одно служебное сообщение. При подозрении на блокировку или CAPTCHA сбор с площадки приостанавливается на 1 час, обходить это не нужно.
- **Нет карточек в dry-run**: окно свежести 6 часов; попробуйте `--max-age-hours 48`.
